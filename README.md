# Neon Bastion

A self-contained HTML/CSS/JavaScript tower defense game.

## Play

Open `index.html` in a browser, or serve this folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls and economy

- Select Pulse, Cannon, or Frost and click open terrain to place it.
- Defeat enemies to earn coins; bosses pay out a large coin bounty.
- Use **Buy Railgun** to spend 350 coins on a powerful long-range shooter, then click the map to place it.
- Press **Deploy Wave** to begin; every tenth wave ends with a boss.
- Use **Pause** when you need a break.
